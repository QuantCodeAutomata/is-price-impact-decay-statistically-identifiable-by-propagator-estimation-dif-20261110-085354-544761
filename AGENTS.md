# AGENTS.md

Guide for coding agents and contributors working in this repository.

## What this repository implements

A replication of selected numerical experiments from *"Is price-impact decay
statistically identifiable by propagator estimation? Diffusive prices force
the inferred kernel to be transient and fine-tuned"*, applied to the
Sato-Fujiwara-Kanazawa (SFK) null model (paper Part II). Two experiments are
implemented:

- **Experiment 1** (`exp/exp1_linear_propagator.py`, paper Fig. 2): linear
  propagator deconvolution on SFK-simulated data for metaorder-size exponents
  `alpha in {1.25, 1.5, 1.75}`.
- **Experiment 2** (`exp/exp2_nonlinear_propagator.py`, paper Fig. 3, End
  Matter): nonlinear (quasi-linear) propagator estimation with daily
  segmentation, for segment lengths `D in {1, 3, 5, 10, 17, 31, 56, 100}` at
  `alpha = 1.5`.

Both experiments are fully synthetic: all data is generated by the SFK model
(`src/sfk_model.py`); no market data, API key, or external dataset is used
anywhere in this repository.

## Layout

```
src/     SFK model simulation, Wiener-Hopf deconvolution, linear/nonlinear
         propagator estimation, power-law fitting, exact-formula cross-check,
         plotting helpers, config.py (all experiment parameters)
exp/     exp1_linear_propagator.py, exp2_nonlinear_propagator.py
data/    generate_synthetic.py -- the only place that produces SFK sample
         paths for the experiments and tests (no data_loader.py: no market
         data is used by either experiment)
tests/   pytest suite for src/ components and experiment configurations
results/ plots, per-experiment summary JSON, and this file's companion
         results/RESULTS.md
```

## Conventions

- All experiment parameters live in `src/config.py` as module-level
  `UPPER_CASE` constants, each with a comment stating its meaning, unit, and
  source (a paper equation/section, or "not specified in the paper"). Do not
  scatter parameters elsewhere.
- Data generation goes only through `data/generate_synthetic.py`, which wraps
  the SFK simulator in `src/sfk_model.py`; `src/` and `exp/` never generate
  sample paths on their own.
- Experiments run from the repository root as `python -m exp.<name>`; tests
  as `python -m pytest`. Do not modify `sys.path` in code.
- No API keys are needed since there is no market-data path in this
  repository; if one is ever added, keys belong only in an uncommitted
  `.env`, following `.env.example`.

## Commands

Setup:

```bash
python -m pip install -r requirements.txt
```

Tests (there is no `market_data` marker in this repository, since neither
experiment uses market data; both commands below are equivalent here):

```bash
python -m pytest
python -m pytest -m "not market_data"
```

Experiments, at the paper-scale configuration (`10^7` simulated steps, 20
seeds; see `src/config.py`):

```bash
python -m exp.exp1_linear_propagator
python -m exp.exp1_linear_propagator --full   # explicit paper-scale run
python -m exp.exp2_nonlinear_propagator
python -m exp.exp2_nonlinear_propagator --full
```

Everything at once:

```bash
bash reproduce.sh
```

## After a rerun

Running the experiment commands above overwrites the plots, `*_curves.npz`
arrays, and `exp1_summary.json` / `exp2_summary.json` files in `results/`.
The numbers and verdicts written by hand in `results/RESULTS.md` are not
regenerated automatically: after a rerun, check them against the new
`results/*summary.json` files and update `results/RESULTS.md` accordingly.
