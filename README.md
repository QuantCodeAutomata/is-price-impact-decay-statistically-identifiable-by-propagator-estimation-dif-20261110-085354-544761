# Is price-impact decay statistically identifiable by propagator estimation?

Replication of selected numerical experiments from:

**"Is price-impact decay statistically identifiable by propagator estimation?
Diffusive prices force the inferred kernel to be transient and fine-tuned"**

The paper proves that, whenever the price process is diffusive, any
propagator inferred by the standard deconvolution methods is forced into a
transient, fine-tuned power-law decay `G(tau) ~ tau^{-beta_c}` even when the
true price impact is strictly permanent and never decays. This repository
reproduces the paper's numerical demonstration of that result on the
Sato-Fujiwara-Kanazawa (SFK) null model, which has permanent square-root
impact and no decay by construction.

## Experiments reproduced

- **Experiment 1 — Linear propagator deconvolution on the SFK null model**
  (paper Fig. 2): the standard linear propagator deconvolution (Eqs. 4a-4c) is
  applied to SFK-simulated order-sign and price series for metaorder-size
  exponents `alpha in {1.25, 1.5, 1.75}`, verifying that the inferred
  propagator decays as `tau^{-beta_c}` with `beta_c = (1 - (alpha - 1)) / 2`.
- **Experiment 2 — Nonlinear propagator estimation with daily segmentation on
  the SFK null model** (paper Fig. 3, End Matter): the quasi-linear
  propagator model of Ref. [18], applied after partitioning the SFK path into
  segments of length `D in {1, 3, 5, 10, 17, 31, 56, 100}` steps, is shown to
  reproduce the same artificial fine-tuned decay for every `D`.

All data is generated synthetically by the SFK model (paper Part II); no
market data is used by either experiment.

## Repository layout

```
src/    SFK model, Wiener-Hopf deconvolution, linear/nonlinear propagator
        estimation, power-law fitting, exact-formula cross-check, config
exp/    exp1_linear_propagator.py, exp2_nonlinear_propagator.py
data/   generate_synthetic.py (the only entry point producing SFK sample
        paths for the experiments and tests)
tests/  pytest suite for src/ components and experiment configurations
results/  plots, per-experiment summary JSON/CSV, RESULTS.md
```

## Setup

```bash
python -m pip install -r requirements.txt
```

No API keys or external data are required: both experiments are fully
synthetic, generated by the SFK model implemented in `src/sfk_model.py`.

## Running the tests

```bash
python -m pytest -m "not market_data"
```

(there is no `market_data` marker in this repository, since no experiment
uses market data; the command above is equivalent to `python -m pytest`.)

## Running the experiments

```bash
python -m exp.exp1_linear_propagator
python -m exp.exp2_nonlinear_propagator
```

Both scripts run at the paper-scale configuration directly (simulation length
`10^7` steps, 20 independent sample paths averaged per setting — see
`src/config.py`); a `--full` flag is accepted for explicitness and runs the
same paper-scale values. Outputs (log-log decay plots and JSON summaries with
fitted vs. theoretical exponents) are written to `results/`.

## Reproduce everything

```bash
bash reproduce.sh
```

## Results

See `results/RESULTS.md` for the comparison against the paper's reported
exponents, deviations, and anything not reproduced.
